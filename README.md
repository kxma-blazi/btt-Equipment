# 🛠️ BTT Field Tool (ระบบจัดการ Tools และอุปกรณ์หน้างาน)

**BTT Field Tool** เป็นเว็บแอปพลิเคชันสำหรับบริหารจัดการและบันทึกข้อมูลเครื่องมือช่างและอุปกรณ์หน้างาน พัฒนาขึ้นด้วย **Google Apps Script (Backend)** และ **Bootstrap 5 / HTML5 (Frontend)** โดยเชื่อมต่อฐานข้อมูลหลักเข้ากับ **Google Sheets** เพื่อความสะดวก รวดเร็ว และสามารถใช้งานผ่านมือถือหรือคอมพิวเตอร์ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

---

## ✨ ฟีเจอร์หลักของระบบ (Features)

* **📊 Dashboard สรุปสถานะภาพรวม:** แสดงจำนวนอุปกรณ์ทั้งหมด, อุปกรณ์พร้อมใช้งาน, อุปกรณ์ที่กำลังถูกยืม และแจ้งเตือนสต็อกต่ำ/ต้องสั่งเพิ่มแบบเรียลไทม์
* **📋 ทะเบียนอุปกรณ์ (Asset Management):** ค้นหา จัดการ เพิ่ม แก้ไข และลบข้อมูลอุปกรณ์ พร้อมระบบแบ่งหมวดหมู่และสถานที่จัดเก็บ
* **📦 ระบบเบิก-คืนอุปกรณ์ (Borrow & Return):** 
  * ระบบตะกร้าสินค้า (Cart) สำหรับเลือกอุปกรณ์หรือสแกน QR Code ต่อเนื่องเพื่อเตรียมเบิก
  * บันทึกชื่อผู้เบิก, ชื่อโครงการ/หน้างาน และสถานที่นำไปใช้งาน
  * รองรับการคืนอุปกรณ์พร้อมบันทึกชื่อผู้คืน
* **📷 รองรับการสแกน QR Code:** ใช้กล้องมือถือสแกน QR Code ของอุปกรณ์เพื่อเปิดดูข้อมูล หรือสแกนเพื่อทำรายการเบิก-คืนได้อย่างรวดเร็ว
* **🖨️ พิมพ์ QR Code:** เลือกรายการอุปกรณ์ที่ต้องการ และสั่งพิมพ์สติกเกอร์ QR Code ได้ทันที
* **🖼️ อัปโหลดรูปภาพ:** รองรับการอัปโหลดรูปภาพอุปกรณ์และเก็บไฟล์เชื่อมโยงผ่าน GitHub Repository
* **🌙 Dark Mode:** รองรับโหมดการแสดงผลแบบมืด (Dark Mode) สบายตาสำหรับใช้งานในเวลากลางคืนหรือหน้างานกลางแจ้ง
* **📝 ระบบ Activity Logs & Audit:** บันทึกประวัติการทำรายการทุกขั้นตอนในระบบ และตรวจสอบความถูกต้องของข้อมูลที่นำเข้า

## 🏗️ โครงสร้างโปรเจกต์ (Project Structure)

โปรเจกต์นี้ประกอบด้วยไฟล์หลักๆ ดังนี้:
* `Index.html` - หน้าจอส่วนติดต่อผู้ใช้งาน (Frontend) ออกแบบด้วย Bootstrap 5 และ SweetAlert2
* `Code.gs` - ชุดคำสั่งฝั่งเซิร์ฟเวอร์ (Backend) จัดการการดึงข้อมูล, บันทึกการเบิก-คืน, ควบคุมสต็อก และจัดการระบบล็อกความปลอดภัย (`LockService`)
* `Config.gs` - ตั้งค่าคอนฟิกต่าง ๆ เช่น ชื่อชีต, ข้อมูลติดต่อผู้ดูแลระบบ และลิงก์ GitHub

## 🚀 วิธีการติดตั้งและใช้งาน (Installation & Deployment)

1. **สร้าง Google Sheet:** สร้างชีตสำหรับเก็บข้อมูลระบบ เช่น ทะเบียนอุปกรณ์, ประวัติการเบิก-คืน, รายชื่อผู้เบิก และ Activity Logs
2. **ติดตั้งสคริปต์:** 
   * เปิด Google Sheets ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
   * นำโค้ดจากโปรเจกต์นี้ (`Code.gs`, `Config.gs`, `Index.html`) ไปวางในโปรเจกต์ Apps Script ของคุณ
3. **Deploy เป็น Web App:**
   * ที่หน้า Apps Script กดปุ่ม **Deploy > New deployment**
   * เลือกประเภทเป็น **Web app**
   * กำหนดสิทธิ์การเข้าถึง (Execute as: *Me*, Who has access: *Anyone*)
   * คัดลอกลิงก์ Web App (ลงท้ายด้วย `/exec`) ไปตั้งค่าในระบบหรือเปิดใช้งาน
4. **ใช้งานผ่านเว็บเบราว์เซอร์:** เปิดลิงก์ Web App ผ่านมือถือหรือคอมพิวเตอร์เพื่อเริ่มใช้งานระบบจัดการ Tools ได้ทันที!
