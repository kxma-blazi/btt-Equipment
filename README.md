# BTT Tool Manager

ระบบจัดการเครื่องมือหน้างาน (เบิก-คืน, ตรวจสต็อก, QR Code) สร้างด้วย **Google Apps Script + Google Sheets** ใช้ผ่านเว็บบนคอมพิวเตอร์และมือถือ ไม่ต้องมีเซิร์ฟเวอร์

## คุณสมบัติ

- **ทะเบียนอุปกรณ์:** ค้นหา กรองตามหมวดหมู่ เพิ่ม แก้ไข ลบ พร้อมรูปภาพ
- **เบิก-ยืม / คืน:** ใช้งานแบบตะกร้า เบิกได้หลายรายการต่อใบ บันทึกผู้เบิก โครงการ สถานที่
- **สแกน QR:** สแกนในระบบด้วยกล้อง หรือสแกนด้วยกล้องมือถือปกติแล้วเปิดระบบเพิ่มของเข้าตะกร้าอัตโนมัติ
- **สต็อกสองกอง (BTT / TKE):** เบิกหัก BTT ก่อนแล้วจึง TKE และคืนเข้ากองเดิม
- **แจ้งเตือนสต็อกต่ำ:** ตามค่า Stock Min
- **พิมพ์ป้าย QR** ทีละหลายรายการ
- **Activity Logs** บันทึกว่าใครทำอะไร และแท็บ **ตรวจสอบข้อมูล** สำหรับข้อมูลที่นำเข้ามา
- **Dark Mode**, รองรับหน้าจอมือถือ
- กันลบอุปกรณ์ที่ยังมีรายการ "กำลังยืม" และใช้ Lock กันการบันทึกชนกัน

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | Backend: อ่าน/เขียน Google Sheets, เบิก-คืน, อัปโหลดรูปไป GitHub, Log |
| `Config.gs` | ค่าตั้งค่า: ID ชีต, ชื่อชีต, ลำดับคอลัมน์, ลิงก์ Web App, ข้อมูล GitHub |
| `Index.html` | Frontend ทั้งหมด (HTML + CSS + JavaScript) |
| `appsscript.json` | Manifest: เขตเวลา, สิทธิ์ (scopes), การตั้งค่า Web App |

## สถาปัตยกรรมโดยสรุป

```
เบราว์เซอร์ (Index.html) --google.script.run--> Code.gs --> Google Sheets
                                                    |
                                                    +--> GitHub API (อัปโหลดรูป)
รูปอุปกรณ์: raw.githubusercontent.com/<OWNER>/<REPO>/main/pic/<รหัส>.jpg
```

## โครงสร้างชีต

**Asset** (ทะเบียนหลัก) ลำดับคอลัมน์ต้องตรงกับ `CONFIG.COL`

| คอลัมน์ | ชื่อ | หมายเหตุ |
|---|---|---|
| A | QR-Code | สูตร (สร้างโดย `setupQrFormulas`) |
| B | Time-Stamp | |
| C | รูปภาพ | สูตร `IMAGE(...)` |
| D | รหัส | ห้ามซ้ำ |
| E | ชื่อรายการ | |
| F | หมวดหมู่ | |
| G | สถานที่จัดเก็บ | |
| H | Stock Max | |
| I | Stock Min | ใช้คำนวณ "ต้องซื้อเพิ่ม" |
| J | ราคา/หน่วย | |
| K | BTT | จำนวนในคลังกอง BTT |
| L | TKE | จำนวนในคลังกอง TKE |
| M | TOTAL | สูตร `=SUM(K:L)` |
| N | สถานะ | พร้อมใช้งาน / ถูกยืม / ชำรุด / ส่งซ่อม / สูญหาย |
| O | ต้องซื้อเพิ่ม | สูตร เทียบ TOTAL กับ Stock Min |
| P | หมายเหตุ | |

**BorrowData:** ลำดับ, รหัส, ชื่อโครงการ, จำนวน, วันที่เบิก, วันที่คืน, ผู้เบิก, สถานที่, สถานะ, หักจาก BTT, หักจาก TKE

**ชีตอื่น:** `SystemLogs` (บันทึกกิจกรรม), `Categories`, `Locations` (รายการตัวเลือก), `ตรวจสอบข้อมูล (นำเข้า)` (รายงานข้อมูลนำเข้า)

> ระบบไม่เขียนทับสูตรในคอลัมน์ TOTAL และ ต้องซื้อเพิ่ม

## การติดตั้ง

### 1. เตรียม Google Sheets
สร้างหรือใช้ชีตที่มีแท็บ `Asset` ตามโครงสร้างด้านบน แล้วคัดลอก Spreadsheet ID จาก URL

### 2. สร้างโปรเจกต์ Apps Script
1. เปิด Google Sheets แล้วไปที่ **Extensions → Apps Script** (หรือสร้างโปรเจกต์แยกที่ script.google.com)
2. วางไฟล์ `Code.gs`, `Config.gs`, `Index.html` และตั้ง `appsscript.json` (เปิด "Show appsscript.json manifest file" ใน Project Settings)
3. แก้ `Config.gs`
   - `SPREADSHEET_ID`: ID ของชีต
   - `GITHUB`: `OWNER`, `REPO`, `BRANCH`
   - `APP_URL`: ใส่หลัง Deploy ในขั้นตอนที่ 4

### 3. รันฟังก์ชันตั้งต้น (ครั้งเดียว)
เลือกฟังก์ชันใน Editor แล้วกด Run (ครั้งแรกต้องอนุญาตสิทธิ์)

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupAll` | สร้างชีต BorrowData / Categories / Locations และซ่อนชีตเก่าที่ว่าง |
| `setupQrFormulas` | สร้างสูตร QR ในชีต Asset ให้เป็นลิงก์ `?code=รหัส` (ต้องตั้ง `APP_URL` ก่อน) |

### 4. Deploy เป็น Web App
**Deploy → New deployment → Web app**
- Execute as: **Me**
- Who has access: **Anyone** (ตามค่าใน `appsscript.json`)

คัดลอกลิงก์ที่ลงท้าย `/exec` ไปใส่ `APP_URL` ใน `Config.gs` แล้วรัน `setupQrFormulas` อีกครั้ง
(หรือวางลิงก์ในแถบเตือนสีเหลืองบนหน้าเว็บ ซึ่งจะเก็บใน Script Properties)

เมื่อแก้โค้ดภายหลัง ให้ **Manage deployments → Edit → New version** ลิงก์เดิมยังใช้ได้

### 5. ตั้งค่าการอัปโหลดรูป (ไม่บังคับ)
1. สร้าง GitHub Personal Access Token ที่มีสิทธิ์เขียนไฟล์ใน repo รูป (เช่น fine-grained token สิทธิ์ **Contents: Read and write**)
2. ใน Apps Script ไปที่ **Project Settings → Script Properties** เพิ่ม `GITHUB_TOKEN` = โทเคนนั้น

## รูปอุปกรณ์

ระบบแสดงรูปจาก `https://raw.githubusercontent.com/<OWNER>/<REPO>/<BRANCH>/pic/<รหัส>.jpg` เท่านั้น

- ชื่อไฟล์ต้องตรงกับรหัสทุกตัวอักษร (ตัวพิมพ์เล็ก/ใหญ่ตรงกัน) นามสกุล `.jpg`
- อัปโหลดจากหน้าเว็บได้ ไฟล์จะถูกบันทึกที่ `pic/<รหัส>.jpg` (เขียนทับถ้ามีอยู่แล้ว) รหัสที่ใช้ได้เฉพาะ `A-Z a-z 0-9 - _`
- หรืออัปโหลดไฟล์เข้าโฟลเดอร์ `pic/` ผ่านเว็บ GitHub โดยตรง
- GitHub แคชไฟล์ประมาณ 1-5 นาที รูปใหม่อาจยังไม่ขึ้นทันที

## หลักการจัดการสต็อก

- **TOTAL = BTT + TKE** และตัวเลขคือของที่ "อยู่ในคลังตอนนี้" (ไม่รวมของที่ถูกยืม)
- **เบิก:** ตรวจว่าจำนวนไม่เกิน TOTAL ถ้าไม่พอจะไม่บันทึกทั้งใบ หักจาก BTT ก่อน เหลือหักจาก TKE และบันทึกจำนวนที่หักลง BorrowData
- **คืน:** คืนเข้ากองเดิมตามที่บันทึกไว้ (รายการเก่าที่ไม่มีบันทึกจะคืนเข้า BTT)
- **สถานะอัตโนมัติ:** TOTAL เป็น 0 → "ถูกยืม", กลับมามากกว่า 0 → "พร้อมใช้งาน" (เฉพาะสถานะสองค่านี้) ส่วน ชำรุด / ส่งซ่อม / สูญหาย ต้องแก้เอง และเบิกไม่ได้
- **ต้องซื้อเพิ่ม:** เมื่อ Stock Min > 0 และ TOTAL ≤ Stock Min
- คืนได้ทีละรายการเต็มจำนวนที่เบิก (ไม่มีคืนบางส่วน)

## QR Code

- QR ในหน้าเว็บและป้ายพิมพ์เก็บลิงก์ `APP_URL?code=<รหัส>` เมื่อสแกนด้วยกล้องมือถือจะเปิดระบบและเพิ่มของเข้าตะกร้า
- ถ้ายังไม่ตั้ง `APP_URL` QR จะเก็บแค่รหัส (สแกนในระบบได้ แต่กล้องมือถือจะไม่เปิดระบบ)
- เปลี่ยนรหัสอุปกรณ์แล้วต้องพิมพ์ป้าย QR ใหม่

## ฟังก์ชันฝั่งเซิร์ฟเวอร์ (เรียกจากหน้าเว็บ)

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `doGet` | เสิร์ฟหน้าเว็บ |
| `getInitialData` | ดึงทะเบียน ประวัติเบิก Log สรุป หมวดหมู่ สถานที่ |
| `saveAssetData(form)` | เพิ่ม/แก้ไขอุปกรณ์ (เปลี่ยนรหัสแล้วอัปเดตประวัติเบิกให้) |
| `deleteAssetData(code, operator)` | ลบอุปกรณ์ (ไม่ให้ลบถ้ายังมีรายการกำลังยืม) |
| `saveBatchBorrowData(payload)` | บันทึกการเบิกหลายรายการ |
| `returnAsset(code, row, operator)` | คืนอุปกรณ์ |
| `uploadImageToGitHub(dataUrl, code, operator)` | อัปโหลดรูปไป `pic/` |
| `saveAppUrl(url)` | บันทึกลิงก์ Web App |
| `logActivity(action, detail, user)` | เขียน SystemLogs |

## ความปลอดภัยและข้อจำกัด

- ตั้งค่า Web App เป็น **Anyone** (ไม่ต้องล็อกอิน) ใครมีลิงก์ก็ดู เบิก แก้ และลบข้อมูลได้ จึงควรเก็บลิงก์ไว้เฉพาะทีมงาน หากต้องการจำกัดสิทธิ์ ให้ปรับ `access` ใน `appsscript.json` และ deploy ใหม่
- ช่อง "ชื่อผู้ใช้งาน" ใน Log เป็นข้อความที่ผู้ใช้กรอกเอง ไม่ใช่การยืนยันตัวตน (เพราะ Execute as: Me ทำให้อ่านอีเมลผู้เข้าใช้ไม่ได้)
- อย่าเปิดเผย `GITHUB_TOKEN` ใน repo ให้เก็บใน Script Properties เท่านั้น
- ตะกร้าเบิกเก็บใน `localStorage` ของเบราว์เซอร์ ไม่ข้ามเครื่อง
- Log ในหน้าเว็บแสดง 50 รายการล่าสุด (ข้อมูลทั้งหมดอยู่ในชีต SystemLogs)
- ควรสำรองชีตเป็นประจำ (File → Make a copy)

## หมายเหตุสำหรับนักพัฒนา

- ลำดับคอลัมน์ในชีต Asset ต้องตรงกับ `CONFIG.COL` ถ้าเพิ่ม/ลบคอลัมน์ต้องแก้ค่าตรงนี้
- ฝั่งเว็บใช้ event delegation และ `escapeHtml` กับข้อมูลที่แสดง เพื่อกัน XSS ถ้าเพิ่มส่วนแสดงผลใหม่ ควรทำแบบเดียวกัน
- ชื่อชีตที่ระบบใช้ทั้งหมดกำหนดใน `CONFIG.SHEETS`
