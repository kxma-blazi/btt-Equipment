# 🛠️ BTT Field Tool Manager (v3.2 Pro)

ระบบบันทึกและจัดการทะเบียนเบิก-คืน อุปกรณ์และเครื่องมือหน้างานแบบ Real-time พัฒนาขึ้นเพื่อช่วยให้ทีมงานสามารถตรวจสอบสถานะ ค้นหาประวัติ และอัปโหลดรูปภาพหน้างานได้อย่างรวดเร็วผ่านเว็บแอปพลิเคชันบนมือถือหรือคอมพิวเตอร์

---

## 🌟 ฟีเจอร์หลักของระบบ (Features)
- 🔍 **ค้นหาและอัปเดตอัตโนมัติ:** ค้นหาด้วยรหัสเครื่องมือ เพื่อดึงข้อมูลเดิมมาอัปเดตสถานะ (เช่น กดคืนเครื่องมือ, แจ้งซ่อม) ได้ทันทีโดยไม่ต้องกรอกใหม่
- 📁 **อัปโหลดรูปภาพแยกไฟล์อิสระ:** รองรับการเลือกรูปภาพหลายรูปพร้อมกัน ระบบจะทำการแยกไฟล์และจัดเก็บลงในโฟลเดอร์ Google Drive แยกตามรหัสเครื่องมือโดยอัตโนมัติ พร้อมลิงก์ดูรูปทั้งหมดใน Google Sheets
- 🌙 **รองรับ Dark/Light Mode:** สลับโทนสีสว่างและมืดได้ตามความต้องการ ป้องกันแสงสะท้อนเวลานำไปใช้งานภาคสนาม
- ⚡ **ดีไซน์ทันสมัย:** ออกแบบด้วย Tailwind CSS สวยงาม ใช้งานง่าย โหลดไว และตอบสนองทุกหน้าจอ (Responsive)

## 🛠️ โครงสร้างไฟล์ในโปรเจกต์ (Project Files)
ในโฟลเดอร์ `Deploy` จะประกอบด้วย 2 ไฟล์หลักสำหรับติดตั้งใน Google Apps Script:
1. **`Code.gs`** - สคริปต์ฝั่งเซิร์ฟเวอร์ (จัดการฐานข้อมูล Google Sheets, ค้นหาข้อมูล, และจัดการโฟลเดอร์/อัปโหลดรูปภาพลง Google Drive)
2. **`Index.html`** - ส่วนติดต่อผู้ใช้งาน (User Interface, ฟอร์มบันทึกข้อมูล, และระบบพรีวิวรูปภาพ)
